# TaskFlow MVP Scope

## Core domains

- Accounts
- Workspaces
- Boards
- Columns
- Tasks
- Notifications

## Included features

### Accounts

- Registration
- Email verification
- Login and logout
- Password reset
- Profile management

### Workspaces

- Create and update Workspace
- Membership roles
- Invitations
- Member management

### Boards

- Create and update Board
- Archive and restore Board
- Display active Columns

### Columns

- Create and update Column
- Archive and restore Column
- Position management

### Tasks

- Create and update Task
- Assignment
- Priority and status
- Due date
- Movement and reordering
- Drag and drop
- Archive and restore
- Basic comments
- Basic activity timeline

### Notifications

- In-app notifications
- Read and unread state
- Unread notification counter
- Task assignment notification
- Task comment notification
- Important Task-change notification

## Deferred features

- Real-time updates
- WebSocket
- Push notifications
- Attachments
- Labels
- Checklists
- Saved filters
- Analytics
- External integrations
- Mentions
- Reactions
- Notification digests
- Advanced notification preferences
